Apps Script Web App URL
⬆ อัปโหลดข้อมูลเก่าขึ้น Google Sheet
สำหรับข้อมูลที่เคยกรอกไว้ในเครื่องนี้ก่อนตั้งค่า Google Sheet
ระบบจะส่งข้อมูลในเครื่องที่ ยังไม่เคยขึ้น Sheet ทั้งหมดไปบันทึกใน Google Sheet
ข้อมูลในเครื่องนี้: กำลังโหลด...
⚠ ต้องตั้งค่าและบันทึก Google Sheet URL ด้านบนให้เรียบร้อยก่อน
⚠ อย่ากดซ้ำหลายครั้ง เพราะข้อมูลอาจถูกบันทึกซ้ำใน Sheet
⚠ จัดการข้อมูล
ข้อมูลทั้งหมดถูกเก็บไว้ใน Browser (localStorage) ของเครื่องนี้

Google Apps Script Code

Copy code ด้านล่างนี้ไปวางใน Google Apps Script ที่ผูกกับ Spreadsheet ของคุณ

const SHEET_ID = 'YOUR_SPREADSHEET_ID_HERE'; const SHEET_NAME = 'AuditResults'; const HEADERS = [ 'timestamp','property','period','staff','position', 'auditor','auditDate','totalScore','effectiveMax','percentage', 'grade','criticalPass', 'cat1','cat2','cat3','cat4','cat5','cat6','cat7', 'criticalDetails','notes' ]; // บันทึกข้อมูล (เรียกตอนกด Submit ในแอป) function doPost(e) { try { const data = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.openById(SHEET_ID); let sheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME); if (sheet.getLastRow() === 0) { sheet.appendRow(HEADERS); } sheet.appendRow([ new Date().toISOString(), data.property, data.period, data.staff, data.position, data.auditor, data.auditDate, data.totalScore, data.effectiveMax, data.percentage, data.grade, data.criticalPass === true, data.cat1, data.cat2, data.cat3, data.cat4, data.cat5, data.cat6, data.cat7, JSON.stringify(data.criticalDetails || {}), data.notes || '' ]); return ContentService .createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({status:'error', msg:err.message})) .setMimeType(ContentService.MimeType.JSON); } } // อ่านข้อมูลทั้งหมด (เรียกตอนเปิด Dashboard / กดรีเฟรช) function doGet(e) { try { const ss = SpreadsheetApp.openById(SHEET_ID); const sheet = ss.getSheetByName(SHEET_NAME); if (!sheet || sheet.getLastRow() <= 1) { return ContentService .createTextOutput(JSON.stringify({data:[]})) .setMimeType(ContentService.MimeType.JSON); } const rows = sheet.getDataRange().getValues(); const headers = rows[0]; const data = rows.slice(1).map(r => { const obj = {}; headers.forEach((h,i) => { let v = r[i]; if (v instanceof Date) v = v.toISOString(); obj[h] = v; }); return obj; }); return ContentService .createTextOutput(JSON.stringify({data:data})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({data:[], error:err.message})) .setMimeType(ContentService.MimeType.JSON); } }

ขั้นตอนการตั้งค่า:

  1. เปิด Google Sheets → Extensions → Apps Script
  2. แทนที่โค้ดเดิมด้วย code ด้านบน และเปลี่ยน YOUR_SPREADSHEET_ID_HERE เป็น ID จริงของ Sheet
  3. Deploy → New Deployment → Web App → Execute as Me → Anyone → Deploy
  4. Copy URL ที่ได้ มาวางในช่อง "Apps Script Web App URL" ด้านบน
  5. กด "ทดสอบการเชื่อมต่อ" เพื่อยืนยัน
